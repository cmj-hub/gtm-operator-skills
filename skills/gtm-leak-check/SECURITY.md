# Security

## What this pack does on your machine

- One script: `skills/gtm-leak-check/scripts/check.py`. Standard-library Python 3. No packages installed.
- `--html-file` reads only the fixture you pass. `--domain` fetches the public homepage, `/robots.txt`, and `/llms.txt`.
- Optional write: `gtm/leak-check.json` in the working tree. Nothing else on disk is changed.
- No CRM, inbox, ads, or JMC account. No paid APIs.

Report vulnerabilities privately to the GitHub Security advisory on this repository.
