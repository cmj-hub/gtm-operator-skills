# Changelog

## 0.1.0 (2026-10-17)

- First public MIT release.
- Instrument: every component in the offer removes a pain the buyer has put a number on.
- Banned: no component without a numbered pain.
- Scorer `skills/offer-stack/scripts/score_stack.py` (stdlib only): prints each pain's yearly cost (count x people x cost each x times a year) and the total; refuses pains with no number or source, a stack built only on assumptions, components that remove no pain, open pains, filler lines, a missing or satisfaction-only risk reversal, and a price larger than the pain.
- Context file `references/offer-stack-context.md`: pain quantification, the five questions, component and guarantee rules, banned lines, honest limits.
- Worked example: a feature list taken to a scored stack.
